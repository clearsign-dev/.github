# ClearSign

Independent transaction verification for high-value crypto signing.

ClearSign reads supported signed fields locally, recomputes the transaction hash
and reports risks and unknowns before approval. It holds no keys and signs
nothing. The project is a developer preview, not a replacement for a hardware
wallet or an independent security assessment.

## Repositories

- [clearsign](https://github.com/clearsign-dev/clearsign): Rust review engine,
  desktop and mobile clients, CLI, embedding interfaces and experimental signer
  platform.
- [clearsign.dev](https://github.com/clearsign-dev/clearsign.dev): source for
  the public website.
